# Docs for contributors

Background for working on Phone2CAD. To use it, start with the
[main README](../../README.md) and [getting started](../getting-started.md).

- [How it works](how-it-works.md): the seven steps from phone video to
  measurements, and what runs where.
- [Roadmap](roadmap.md): known problems and planned work, most important first.
  Each item can become an issue.
- [Benchmark](BENCHMARK.md): the real-capture benchmark, its metrics and
  results, and how other scanning tools compare.
- [Security review](security-review.md): what was checked before v1.0.0, what
  was fixed, and the known remaining risks.
- [Contributing](../../CONTRIBUTING.md): development setup, tests and rules.
- [Accuracy](../accuracy.md): test results and how to score your own scans
  against a CAD model.
